## Create Models/Entities and Implement CRUD APIs

Implemented the required models/entities and CRUD (Create, Read, Update, Delete) REST APIs for the Legal Contract Management System using Spring Boot, JPA/Hibernate, and PostgreSQL.

### Models/Entities

* User
* Role
* Contract
* Contract Status
* Document
* Clause
* Modification
* Approval
* Approval Status
* Version
* Audit Log

### CRUD Operations

Implemented REST APIs to:

* Create new records
* Retrieve records
* Update existing records
* Delete records

### API Methods

* **POST** – Create
* **GET** – Read
* **PUT** – Update
* **DELETE** – Delete

### Database

The APIs are integrated with PostgreSQL using Spring Data JPA/Hibernate.
