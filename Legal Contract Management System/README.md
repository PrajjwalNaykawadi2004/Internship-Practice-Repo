# Legal Contract Document Modification System

## Project Overview

The Legal Contract Document Modification System is a secure web-based application developed using Java Spring Boot and PostgreSQL.

The system allows authorized users to upload, manage, review, modify, and track legal contract documents digitally.

## Main Features

- Upload and manage legal contract documents
- View and review contracts
- Modify contract details and clauses
- Maintain previous and modified versions
- Version control
- Approval and rejection workflow
- Modification history tracking
- Audit/history tracking
- Role-based access control
- Secure REST APIs

## Technology Stack

- Java
- Spring Boot
- Spring Security
- Spring Data JPA / Hibernate
- PostgreSQL
- REST API
- Maven
- Git & GitHub

## Project Workflow

Upload Contract → Review Contract → Modify Clause → Save New Version → Send for Approval → Approve/Reject → Maintain History
