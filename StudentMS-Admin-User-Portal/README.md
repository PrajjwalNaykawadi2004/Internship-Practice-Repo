# Student Management System Portal

A Full Stack Student Management System developed during internship.

## Features

### Admin Module
- Admin Login
- Admin Dashboard
- User Management
- Add Student
- View Students
- Profile Management
- Profile Photo Upload
- Change Password

### User Module
- User Login
- User Dashboard
- View Profile
- Update Profile
- Change Password
- Forgot Password with OTP Verification

## Technologies Used

### Backend
- Java
- Spring Boot
- Spring Security
- JWT Authentication
- Hibernate
- MySQL

### Frontend
- HTML
- CSS
- JavaScript
- Bootstrap

## Project Description

This application provides a platform to manage students and users with secure authentication, role-based access, profile management, and OTP-based password recovery.
